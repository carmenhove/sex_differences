
This repository contains all de-identified NHANES data and R code used to generate the main and supplementary analyses, figures, and tables reported in the manuscript titled "Female reproductive status and ecological conditions impact the magnitude of sex differences in human immune status" by Carmen Hove, Michael Gurven, Benjamin Trumble, Jonathan Stieglitz, Daniel Eid Rodriguez, Ivan Maldonado Suarez, Hillard Kaplan, Aaron Blackwell, and Amy Boddy. 

To request access to the Tsimane Health and Life History Project data, please email Carmen Hove at carmenhove@ucsb.edu. 

1. Download repostory to folder on local computer
2. Open sex_differences.Rproj in R Studio (or other GUI, such as VS code) 
3. Run all R scripts in the "scripts" subfolder in numerical order (01_, 02_, and so on)
